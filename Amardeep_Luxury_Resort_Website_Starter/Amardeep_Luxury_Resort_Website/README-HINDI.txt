AMARDEEP LUXURY RESORT WEBSITE
================================

PROJECT MEIN KYA HAI
- index.html: website ka content
- style.css: design, colours aur responsive layout
- script.js: menu, gallery preview aur enquiry form
- config.js: WhatsApp number aur contact details
- assets/: aapke resort ki original photos aur edited cinematic hero image

COMPUTER PAR WEBSITE KAISE DEKHEIN
1. ZIP file extract karein.
2. VS Code kholein.
3. File > Open Folder par click karke Amardeep_Luxury_Resort_Website folder select karein.
4. index.html par right-click karke Open with Live Server karein.
   (Live Server extension installed na ho to VS Code Extensions mein "Live Server" search karke install karein.)
5. Browser mein website khul jayegi.

WHATSAPP BOOKING ACTIVATE KARNA
1. config.js file kholein.
2. whatsappNumber ke quotes ke beech owner ka confirmed number likhein.
   India example format: 91XXXXXXXXXX (sirf digits; + ya spaces nahi).
3. Save karein.
4. Website reload karein.

IMPORTANT:
- Abhi phone number aur location jaan-boojhkar placeholder hain. Client se asli details confirm karke hi add karein.
- Room photos abhi nahi mili hain, isliye room section mein resort building ki photo temporary hai.
- Event capacity, room prices, address, availability aur extra facilities confirm hone ke baad hi publish karein.

GITHUB PAGES PAR FREE PUBLISH
1. GitHub par login karein aur New repository banayein.
2. Repository ka naam amardeep-luxury-resort rakhein.
3. Public select karke Create repository karein.
4. Is folder ke andar ki sab files aur assets folder GitHub repository mein upload karein.
   Dhyan rahe: index.html repository ke root mein hona chahiye.
5. Repository > Settings > Pages kholein.
6. Build and deployment mein Deploy from a branch select karein.
7. Branch: main aur folder: /(root) select karke Save karein.
8. Kuch minute baad Pages section mein live website link aa jayega.

Website ek static front-end hai. Booking enquiry WhatsApp par bhejne ke liye config.js mein real number zaroor add karein.
